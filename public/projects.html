Student Information & Enrollment System

Capstone Project · PHP, MySQL, Bootstrap 5
System Overview & Architecture

This application was engineered to resolve long physical queues during university enrollment periods. It replaces manual paper forms with an online workflow where students can view open course slots, enroll in prerequisite-checked subjects, and view their unofficial transcript of records.

Role-Based Access
Distinct portals for Students, Faculty Instructors, and the University Registrar.
Normalized Relational Schema
Designed up to 3NF in MySQL ensuring integrity with foreign key constraints.
Key Academic Learnings:

Gained deep hands-on expertise in SQL transactional queries (BEGIN, COMMIT, ROLLBACK), session management in PHP, and responsive grid layouts using Bootstrap 5.
